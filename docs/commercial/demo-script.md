# Commercial Demo Script

## 7 To 10 Minute Demo

### 1. Business-First Opening

"Nkeanyi-AI Trust Flow System is built for regulated organizations that want to use AI in real business workflows without losing auditability, tenant isolation, or operational control. The product helps teams prove what happened across documents, AI-generated knowledge, payments, and compliance evidence."

### 2. Problem Narrative

"The problem is not that teams lack logs. The problem is that logs are fragmented, technical, and hard for compliance or operations teams to use. When an AI-assisted workflow touches documents, knowledge generation, payment orchestration, and evidence storage, leaders need one correlation-level view that explains what happened and whether the workflow is ready, incomplete, or requires review."

### 3. Workflow Walkthrough

"In this demo, we run a regulated trust flow. A document is processed, a grounded knowledge answer is generated, a payment workflow is created with idempotency and replay safety, and compliance evidence is recorded across the services. Each step carries tenant and correlation context so the workflow can be reviewed as one business event."

Show:

- Tenant ID
- Correlation ID
- Document processing event
- Knowledge answer event
- Payment received and completed events
- Compliance evidence records

### 4. Evidence Summary Walkthrough

"Instead of asking an engineer to read service logs, NAITFS exposes dashboard-ready evidence summaries. For a correlation ID, we can see the total evidence, evidence types, source services, first and last event time, and workflow status."

Show:

- Correlation summary endpoint
- Evidence count
- Evidence types
- Source services involved
- Status such as `COMPLETE`, `INCOMPLETE`, or `REVIEW_REQUIRED`

### 5. Dashboard Walkthrough

"For executives and operations teams, the dashboard turns the same evidence into a business-readable view. It shows the tenant, readiness status, total evidence, total correlations, evidence by type, recent trust flows, source services, and last event time."

Show:

- Readiness badge
- Tenant metrics
- Evidence by type
- Recent trust flows table
- Service participation panel

### 6. Buyer Takeaway

"The takeaway is that NAITFS does not just automate a workflow. It makes the workflow provable. Compliance gets evidence packages, operations gets status visibility, and platform teams get API-level controls for tenant, correlation, and idempotency behavior."

### 7. Closing Call-To-Action

"The right next step is a 30-day pilot around one regulated workflow. We would identify one document, AI, payment, or compliance-sensitive process, connect the required APIs or event sources, and prove whether NAITFS can produce useful evidence packages for your audit and operations teams."
