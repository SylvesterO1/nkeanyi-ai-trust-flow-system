# Pricing Hypothesis

## Starter Pricing

- $2,500 to $5,000 per month
- One workflow
- One environment
- Limited evidence event volume
- Basic dashboard and API evidence summaries
- Standard support

## Growth Pricing

- $8,000 to $18,000 per month
- Multiple workflows
- Higher evidence event volume
- Expanded tenant reporting
- Advanced integration support
- Quarterly evidence review sessions

## Enterprise Pricing

- $50,000+ per year, with larger deployments priced by scope
- Multiple business units or regulated workflows
- Custom deployment and retention requirements
- Dedicated onboarding and security review support
- Enterprise support and success planning

## Usage-Based Evidence Event Model

Usage can be priced by evidence events recorded per month. An evidence event is a compliance-relevant record generated by a document, knowledge, payment, audit, failure, or manual evidence step.

Example bands:

- Included monthly evidence events per plan
- Overage price per 10,000 evidence events
- Higher retention tiers for customers with long audit windows
- Separate pricing for high-volume event ingestion

## Pilot Pricing

- 30-day pilot: $15,000 to $35,000
- Scope includes one workflow, one tenant model, API validation, dashboard walkthrough, and pilot readout
- Optional credit toward annual subscription after conversion

## Professional Services And Onboarding

- Standard onboarding: $10,000 to $25,000
- Custom integration package: $25,000 to $75,000
- Compliance reporting package: custom
- Security review and deployment architecture support: custom

Pricing should be validated through customer discovery. Early customers may value risk reduction, audit readiness, and integration support more than raw event volume.
